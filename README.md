# EDA-PROJECT-S-
# 📊 Exploratory Data Analysis (EDA) Projects

Welcome to my **EDA Projects Repository**! This repository contains data analysis projects developed using Python and its data analysis libraries.

## 🚀 Projects

### 1. Netflix Content Analysis
- **Objective:** Analyze Netflix movies and TV shows.
- **Analysis:** Content types, ratings, countries, durations, and release-year trends.
- **Tools:** Python, Pandas, Matplotlib.

### 2. Heart Disease Analysis
- **Objective:** Explore health-related data and identify patterns associated with heart disease.
- **Analysis:** Data exploration, statistical summaries, and visualization of dataset features.
- **Tools:** Python, Pandas, Matplotlib.

### 3. Insurance Data Analysis
- **Objective:** Explore insurance data and understand patterns in insurance charges.
- **Analysis:** Data cleaning, descriptive statistics, feature relationships, and visualizations.
- **Tools:** Python, Pandas, Matplotlib.

## 🛠️ Technologies Used

## ⚙️ How to Run

1. Clone or download the repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib jupyter
   ```

3. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open the relevant `.ipynb` file and run the cells.
